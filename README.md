# Word & Character Counter Tool

A fast, lightweight, and privacy-focused client-side web tool for counting words, characters, and paragraphs in real time.

All operations run entirely in your web browser. No text data is transmitted, collected, or stored on any external server.

## Features

- **Real-Time Analysis:** Statistics update automatically as you type or paste text.
  - **Words:** Accurately counts words separated by spaces, tabs, and line breaks.
  - **Characters (with spaces):** Total character count.
  - **Characters (no spaces):** Character count excluding all whitespace and line breaks.
  - **Lines / Paragraphs:** Total number of non-empty lines and paragraphs.
- **Number Formatting:** Displays large numbers with comma separators (e.g., `1,000`) for readability.
- **Client-Side Execution:** Fast and secure without backend dependencies.
- **Quick Controls:**
  - **Copy Text:** One-click copy of the current text to your clipboard.
  - **Clear All:** Instantly resets the text area and counters.
